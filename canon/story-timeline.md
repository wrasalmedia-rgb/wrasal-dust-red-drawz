# Story timeline

This file is a placeholder for the project’s timeline and narrative progression. It should remain deliberately non-canonical until reviewed and approved.

## Timeline status

- Draft status: proposed
- Canon status: pending approval
- Review status: not yet approved

## Timeline structure

Use the following structure for each timeline entry:

- `timeline_id`: stable ID
- `title`: event or sequence title
- `phase`: pre-production / production / late production / release
- `summary`: short description
- `evidence`: references or rationale
- `status`: proposed | reviewed | approved | archived

## Example row

```yaml
- timeline_id: timeline-001
  title: Opening incident
  phase: pre-production
  summary: Proposed trigger event for initial story setup.
  evidence: Notion brief / research notes / internal review
  status: proposed
```

## Required review before canonization

Before a timeline entry becomes canon, it must be reviewed for:

- continuity consistency,
- character coherence,
- world-building fit,
- approved narrative direction,
- and asset impact.

# Character register

This file is a placeholder for the approved and proposed character ledger. It should not be treated as canon unless the entries are explicitly marked approved.

## Character record schema

Each character should use the following fields:

- `character_id`
- `name`
- `role`
- `status`
- `summary`
- `source`
- `canonical_status`
- `notion_ref`

## Example entry

```yaml
- character_id: char-001
  name: TBD
  role: protagonist
  status: proposed
  summary: Character description pending human review.
  source: Notion brief
  canonical_status: proposed
  notion_ref: character-001
```

## Intent

This record works as a reviewable ledger rather than a permanent canon declaration. Human review determines when a character becomes canonical.

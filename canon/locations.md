# Location registry

This file records the world and spatial logic of the project. It is a placeholder until reviewed and approved.

## Location record schema

- `location_id`
- `name`
- `type`
- `status`
- `summary`
- `relationship_to_story`
- `canonical_status`

## Example entry

```yaml
- location_id: loc-001
  name: TBD
  type: primary setting
  status: proposed
  summary: Setting description pending review.
  relationship_to_story: core narrative environment
  canonical_status: proposed
```

## Review rule

Any location intended for canon must pass continuity and storytelling review before it is marked approved.

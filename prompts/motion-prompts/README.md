# Motion prompt family

Motion prompts drive animation, movement, timing, camera force, and performance characteristics. Keep them separate from the narrative and symbolic decision records.

## Required fields

- `prompt_id`
- `shot_id`
- `status`
- `motion_descriptor`
- `timing_notes`
- `camera_notes`
- `review_status`

## Example

```yaml
prompt_id: prompt-motion-001
shot_id: shot-001
status: proposed
motion_descriptor: slow drift reveal
timing_notes: ambient pacing
camera_notes: wide framing with subtle handheld motion
review_status: not-reviewed
```

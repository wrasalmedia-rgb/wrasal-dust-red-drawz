## 1. The 7-Tier Visual Reference Hierarchy (Stage D)

To prevent character identity drift, spatial incoherence, lighting contamination, and unauthorized canon mutation across image and video generation tools, every visual description, reference plate, and generated file in `WRASAL DUST: THE RED DRAWZ` is governed by a strict **7-state reference hierarchy**:

| Rank | Hierarchy State | Governance Status Mapping | Definition & Authority | Permitted Production Use | Promotion / Demotion Gate |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | **Canonical character / world description** | `CANON` | Immutable text facts locked by the human creative authority in `canon/*.md` (e.g., Harlem 2026 setting; Mister Grant widower <2-year marriage; Wrasal apprentice speaking composed standard British English; red garments materially red; deceased wife's nature unconfirmed). | Mandatory constraint block (Section 3) in every prompt. Cannot be overridden by any visual reference or style preset. | Only the human creative authority can create or revise `CANON` text. |
| **2** | **Approved visual reference** | `APPROVED ASSET` (Tier 00 Anchor) | Human-approved master reference plates (`FACE_MASTER`, `BODY_MASTER`, orthographic turnaround, location plate, or fabric swatch) stored with immutable provenance. | Required visual input (Section 4) for any image-to-image, character-lock, or image-to-video generation depicting that subject. | Promoted from `Tested candidate` **solely** by explicit human creative authority sign-off (`S5 / Authorize`). |
| **3** | **Approved production asset** | `APPROVED ASSET` (Shot Master) | A specific scene keyframe, motion clip, or audio stem that has passed all S3/PHOTOCRITIC checks and received explicit human steward approval for inclusion in the Case 001 edit. | Locked in the sequence cut (`shotlists/case-001.yaml`) and usable as an incoming/outgoing continuity anchor (`continuity_in` / `continuity_out`) for adjacent shots. | Requires `Approved visual reference` upstream + 100% pass on `verification/continuity-checklist.md` + human sign-off. |
| **4** | **Tested candidate** | `TESTED` | A generated image, video clip, or audio file that has been evaluated against measurable acceptance criteria (`verification/acceptance-criteria.md`) with full scores and provenance logged in a verification record (`schemas/verification.schema.json`). | Eligible for human creative review and comparison; **cannot** be used as a canonical identity anchor or published before human promotion to `APPROVED ASSET`. | Promoted from `Generated candidate` after executing the S3 verification checklist and logging pass/fail evidence. |
| **5** | **Generated candidate** | `IN BUILD` / `READY FOR TEST` | Raw output from an image, video, or audio generation run produced under a structured prompt (`prompts/master-shot-template.md`), prior to formal verification scoring. | Inspection and S3/PHOTOCRITIC audit only. Must never be fed back into a generator as a character identity anchor (prevents recursive generational drift). | Automatically demoted to `Rejected candidate` if it fails any hard canon, identity, or material gate. |
| **6** | **Rejected candidate** | `NEEDS REVISION` / `SUPERSEDED` | Any candidate that failed one or more continuity, identity, lighting, material, or story constraints (e.g., red light bleed onto walls, facial drift, ghost shader on deceased wife, tropical flora in Harlem). | Archived in failure logs with explicit failure rationale (`qa_issues / revision_rationale`) to calibrate negative prompts; **prohibited** from edit or reference reuse. | Terminal state for that specific output; requires prompt or reference repair before a new candidate is generated. |
| **7** | **Unresolved reference** | `REFERENCE NEEDED` | A character, location, wardrobe, or prop whose canonical existence is known in `canon/*.md`, but for which no human-approved Tier 00 visual reference plate exists in accessible storage. | **Hard Blocker** for final character/scene production. Only non-identity-bearing tests (e.g., environment/prop lighting calibration clearly labeled `PROPOSED`) may proceed while a subject is in this state. | Remains blocked until the human creative authority supplies or approves a Tier 00 visual reference pack. |

## 2. Anti-Drift Protection Rules Across the Hierarchy

1. **Zero Recursive Generation Drift**: A `Generated candidate` (State 5) or unapproved `Tested candidate` (State 4) may **never** be used as the primary facial identity anchor (`FACE_MASTER`) for subsequent shots. Every shot of a character must anchor back to the original Tier 00 `Approved visual reference` (State 2), paired with the immediate prior `Approved production asset` (State 3) only for local lighting/pose continuity.
2. **Text Canon Overrides Visual Drift**: If an `Approved visual reference` or `Generated candidate` accidentally introduces an element that contradicts `Canonical character / world description` (State 1) — such as bathing a room in red light instead of rendering a materially red garment — State 1 (`CANON`) governs and forces `NEEDS REVISION`.
3. **Ontological Restraint Gate**: For `char-deceased-wife-001`, no candidate may pass from State 5 (`Generated candidate`) to State 4 (`Tested candidate`) if the renderer introduces supernatural horror tropes (translucency, glowing eyes, decay, or dream-blur) that violate the canonical ambiguity of her appearance in the practitioners' astral mental chambers (`decision-005`).

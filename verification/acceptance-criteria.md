# Verification and validation notices

This repository is intended to preserve a strict separation between evidence, interpretation, and approval. Validation records must reflect actual evidence and cannot be treated as a substitute for human judgment.

## Required evidence practices

- Keep source references and observed evidence distinct from interpretation.
- Record assumptions and unknowns explicitly.
- Keep continuity outcomes separate from creative preference.
- Preserve the status of each output: proposed, generated, verified, approved.

## Intended usage

Use this directory to hold review criteria, checklists, and structured generation logs. Maintain version control so the project’s decisions can be traced and questioned later.
